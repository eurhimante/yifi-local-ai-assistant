# YIFI v0.3.2 — Secure Web Fetch

## Summary

YIFI can now retrieve readable text from approved HTTPS webpages
using a new `web_fetch` tool, complementing `web_search` and
`github_latest_release`.

## Features

- HTTPS-only webpage retrieval
- Strict domain allowlist
- Public-IP validation and pinned DNS resolution
- Redirect refusal
- Response-size and extracted-text limits
- HTML text extraction
- Integration with the YIFI tool-calling orchestrator
- Server-generated provenance for successfully retrieved pages
- OpenAI-compatible SSE responses retained

## Validation

- 16 automated tests passed
- Real HTTPS retrieval verified
- `web_search` followed by `web_fetch` verified
- SSE compatibility verified in DEV
- Docker Compose production deployment successful
- End-to-end LibreChat test successful with `yifi:4b`

## Limitations

- Only allowlisted HTTPS domains can be fetched
- Retrieved webpage content remains untrusted
- Retrieval does not independently verify factual claims
- SSE output is not yet token-by-token streaming
- The model can still generate unsupported metadata or overly long answers

## Rollback

The previous v0.3.1 production image and source files were backed up
before deployment.
